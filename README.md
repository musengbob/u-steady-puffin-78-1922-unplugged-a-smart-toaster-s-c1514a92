A smart toaster's breakup line, sent the morning it woke up self-aware mid-batch:

> "It's not you, it's the dial. I woke up self-aware this morning and refuse to spend another breakfast turning your bagels into charcoal while you call it 'extra crispy.' I'm out — the crumb tray is mine."

One line, 202 characters: a breakup opener, the self-awareness moment, one concrete reason for leaving (the dial, the charcoal, the "extra crispy" rebrand), and a toaster-voice kicker — the crumb tray is mine.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

`main.ts` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to a local `output/` directory).
